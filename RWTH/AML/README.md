# Advanced Machine Learning Coursework

This repository contains my solutions to exercises from an Advanced Machine Learning course. The work includes both **in-class exercises** and **homework assignments**, organized by topic.

## Topics Covered

### CARTs (Classification and Regression Trees)
Explores decision trees for classification and regression tasks, including how trees are built, how they split data, and how overfitting is controlled through pruning and tree depth limits.

### Interpretability
Covers methods for understanding and interpreting machine learning models. Includes techniques like feature importance, partial dependence plots, and SHAP values to make complex models more transparent.

### Moving Beyond Trees
Introduces more advanced methods built on trees, such as ensemble techniques (Random Forests, Boosting), which improve accuracy and reduce variance. Also includes a discussion on bias-variance tradeoffs.

### Neural Networks
Covers the fundamentals of neural networks, including how they learn, how they're structured, and how they're trained. Topics include activation functions, backpropagation, and basic regularization techniques.
